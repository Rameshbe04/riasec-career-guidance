# RIASEC College Career Guidance Survey

A starter Streamlit web app based on the supplied 42-item RIASEC questionnaire.

## Included
- 42 statements across Realistic, Investigative, Artistic, Social, Enterprising, and Conventional dimensions.
- Five-point response scale and automatic scoring (7 items per dimension; 7–35 points).
- Top-three interest code, exploratory career suggestions, and suggested next steps.
- Downloadable text report.
- No database or response storage in this starter version.

## Publish online
1. Create/sign in to a GitHub account and create a new repository.
2. Upload `app.py` and `requirements.txt` (you may also upload this README).
3. Open https://share.streamlit.io/ and sign in with GitHub.
4. Choose **Create app**, select your repository and `app.py`, then deploy.
5. Copy the public app URL and share it with students.

You can test locally first with Python 3.10+: `pip install -r requirements.txt` followed by `streamlit run app.py`.

## Important notes
- The app provides exploratory suggestions, not a validated diagnosis or guarantee of career success.
- Career suggestions are general examples; review them for your students' degree programmes and local opportunities.
- Responses are not stored in this starter version. Add a privacy notice and secure storage only if you later decide to collect responses for analysis.
- Review the questionnaire wording and scoring rules before using this tool for formal research.
